## 四、隐私声明两条路

### 路 A：隐私托管（推荐，零 URL）
AGC「隐私声明 → 管理方式」选 **隐私托管**，按模板填写：
- 开发者名称：山东管理学院
- 联系方式：学校信息中心/网络信息中心对外邮箱或电话（需学校提供真实值）
- 收集信息清单：直接参照 `隐私政策.md` 第二节逐条录入
- 托管后华为自动在应用详情展示，App 内无需改动

### 路 B：自定义隐私政策（需要 URL）
1. 把 `隐私政策.md`（或 `隐私政策.html`）交学校信息中心发布到官网，如 `https://www.sdmu.edu.cn/xygk/yszc.htm`
2. AGC 填该 URL
3. **App 内同步改**：`PhoneLoginPage.ets` L419 与 `LoginPage.ets` 协议链接的 `url` 参数替换为同一 URL（两处《隐私政策》《服务协议》共 4 处），重新构建
4. 未发布 URL 前不要提交审核（审核会点开链接核验）

## 七、审核注意事项（自查清单）

1. **测试账号**：AGC 提审需提供可登录的测试账号密码（用学校分配的真实学生账号），在「版本信息 > 测试信息」填入
2. **登录方式**：账号密码 + 手机号验证码双通道均可走通；验证码短信通道需确认在校外网络可达
3. **隐私弹窗**：首次启动展示隐私政策弹窗（已实现），不同意不可进入 ✓
4. **权限最小化**：WRITE_CONTACTS（保存到通讯录）、APPROXIMATELY_LOCATION（督评定位）均按功能场景申请 ✓
5. **敏感服务提示**：一卡通等财务服务仅校园网内可用，错误页已明确提示（审核可能在办公网测试，需在测试信息中说明该限制）
6. **测试信息备注模板**：见 `测试信息备注.txt`
